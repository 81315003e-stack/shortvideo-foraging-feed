# 刺激影片選片標準

版本：v0.5（2026-10-07）｜對應 proposal：*Keep Watching or Swipe Away?*（2×2 受試者內設計，4 個 5 分鐘 block）

本文件規定「哪些影片可以進入片庫、如何分組、如何處理」。每支影片的判定細節見 [`CODEBOOK.md`](CODEBOOK.md)。

---

## 1. 片庫規模與分組

| 組別 | 內容 | 正式施測 | pilot |
|---|---|---|---|
| HS-A | 高 scent 第 1 組 | 30 支 | 20 支 |
| HS-B | 高 scent 第 2 組 | 30 支 | 20 支 |
| LS-A | 低 scent 第 1 組 | 30 支 | 20 支 |
| LS-B | 低 scent 第 2 組 | 30 支 | 20 支 |
| 練習 | 不計分 | 2 支 | 2 支 |

- 每個 block 對應一個條件（摩擦 × scent），播放一組影片
- 每組影片在一半受試者出現在零摩擦條件，在另一半出現在微摩擦條件（與拉丁方格一起平衡）
- 每組 30 支足以涵蓋平均每支停留 10 秒以上的受試者；pilot 後依實際停留時間分布調整
- 同一位受試者不會重複看到同一支影片

## 2. 納入條件（全部符合）

1. **AI 生成的微短劇**：畫面或配音可辨識為 AI 生成（判斷依據見編碼簿 A6）
2. **單一完整段落**：長度 15–60 秒，有可理解的開頭，結尾落在場景或句子結束處。可以是原片，也可以是從較長單集剪出的片段（第 7.2 節）
   - 開場窗口是前 10 秒，**短於 20 秒的影片開場之後只剩不到 10 秒**，mismatch（編碼簿 C）與崩壞點（C4）較難判定。這類影片的 C 欄位可標「無法判定」，且**不放進高 scent 組前 8 個位置**（第 5 節）
3. **直式 9:16**，原始解析度至少 720p
4. **語言**：國語為主；台語、客語或其他語言另外標記（編碼簿 A8），同組內比例一致
5. **有字幕**（高齡者常關靜音或聽力受限，字幕是主要資訊來源）
6. **公開可取得**，並記錄原始網址與下載日期

## 3. 排除條件（任一符合即排除）

1. 政治、宗教宣傳、選舉相關
2. 血腥暴力、性暗示、自傷或自殺情節
3. 醫療、投資、保健食品等可能誤導受試者的具體建議
4. 導購、業配、明顯廣告或 QR code
5. 近期爆紅、受試者可能已看過（播放數極高或曾登上新聞）
6. 真人明星或可辨識公眾人物的臉
7. 片頭或片尾有無法去除、且與其他影片不一致的品牌浮水印
8. 同一部劇在正式片庫中已有 1 段（避免受試者認出同一劇的角色，而把後一段當成「續集」繼續看）；第 2 段只能作練習或備用
9. 來源不明的轉載（標示「紅果短劇」「快手」「全集整合」等搬運帳號），除非找得到原作者並取得同意
10. 同一創作者帳號在同一組已有 3 支

## 4. 高 scent 與低 scent 的操作型定義

判定規則見編碼簿 B4，這裡是選片時的概念標準。

**開場窗口：影片最前面 10 秒。** pilot 後依高齡者 `first_touch_ms` 分布校正（例如多數人在 6 秒內觸碰，就把窗口縮到 6 秒）。

| | 高 scent | 低 scent |
|---|---|---|
| 鉤子出現時間 | 第 5 秒內 | 前 10 秒內沒有 |
| 鉤子類型 | 衝突對白、道德評判字幕、誇張 AI 表情（至少一種） | 無 |
| 開場張力強度 | 3 或 4 分（編碼簿 B3） | 0 或 1 分 |
| 影片類型 | AI 微短劇 | **AI 微短劇**（開場平淡、慢慢鋪陳的段落）；不足時才用日常生活類 AI 影片，並在 Limitations 說明 |
| 內容價值（編碼簿 D12） | 以 `hedonic` 為主 | 與高 scent 組的分布一致，**不可用 `utilitarian` 影片充當低 scent** |

張力強度 2 分或判定為「不確定」的影片，不放入任何一組。

**為什麼低 scent 也要用微短劇**：如果高 scent 都是微短劇、低 scent 都是生活影片，差異可能來自影片類型，而不是開場 scent。生活影片也常偏向實用資訊；享樂用途與實用用途對高齡者的使用行為作用方向相反（Wang et al., 2026），會讓 scent 和內容價值混在一起。

**開場 scent 不等於視覺刺激**：高 scent 的定義是開場**內容**承諾了值得看的東西（衝突、評判、誇張表情），不是畫面剪得比較快。高齡者對突然出現的視覺刺激特別容易被吸引（Pratt & Bellomo, 1999），所以兩組在開場視覺顯著性上要盡量一致（第 6 節），讓 scent 的效果不會被視覺刺激的效果取代。

## 5. 高 scent 組內的 mismatch 配置（H3）

H3 需要受試者反覆遇到「開場強、內容撐不住」的影片。

- 每組高 scent 影片中，**mismatch 約占一半**（30 支中 14–16 支），其餘為「開場強且有兌現」
- 看得慢的受試者一個 block 可能只看到 3–4 支，所以**前 8 個位置要固定模式**，兩組使用相同排列：

  | 位置 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
  |---|---|---|---|---|---|---|---|---|
  | 類型 | M | M | F | M | F | M | M | F |

  M = mismatch，F = 有兌現。第 9 支之後交錯排列，避免連續 3 支同類型
- 低 scent 組也照編碼簿編 mismatch，但不刻意安排位置

## 6. 組間配對

### 6.1 高 scent 與低 scent 之間（只差在開場內容）

| 項目 | 配對標準 |
|---|---|
| 開場 10 秒鏡頭切換次數（D8） | 平均差距 ≤ 1 次 |
| 字幕彈出動畫（D9）、突然放大或閃白（D10） | 有該特徵的支數差距 ≤ 3 支（每組 30 支） |
| 內容價值（D12） | `hedonic`、`mixed` 的支數差距 ≤ 3 支 |
| 影片長度 | 平均差距 ≤ 5 秒 |
| 長度分布（15–29、30–44、45–60 秒三段） | 各段支數差距 ≤ 3 支 |
| 結尾類型為 `open` 的支數（編碼簿 A5d） | 差距 ≤ 3 支 |

如果高 scent 影片的視覺顯著性普遍比較高、實在配不起來，先在 pilot 檢查 D8–D10 與停留時間的關係，並在分析時納入共變項；論文中要說明殘留的差異。

### 6.2 同一 scent 的 A 組與 B 組之間（兩組要對等）

HS-A 與 HS-B、LS-A 與 LS-B 在下列項目上要接近。建組後用編碼資料檢查，差異過大就互換影片。

| 項目 | 配對標準 |
|---|---|
| 影片長度 | 平均差距 ≤ 5 秒 |
| 長度分布（15–29、30–44、45–60 秒三段） | 各段支數差距 ≤ 2 支 |
| 結尾類型為 `open` 的支數 | 差距 ≤ 2 支 |
| 原片與剪輯片段的比例 | 差距 ≤ 3 支 |
| 開場張力強度 | 平均差距 ≤ 0.3 分 |
| 鉤子出現時間 | 平均差距 ≤ 1 秒 |
| 鉤子類型分布 | 各類型支數差距 ≤ 2 |
| mismatch 支數 | 相同 |
| 前測分數（第 9 節） | 平均差距 ≤ 0.3 分 |
| 語言、AI 配音比例 | 相同或差距 ≤ 2 支 |
| 開場 10 秒鏡頭切換次數（D8） | 平均差距 ≤ 1 次 |
| 內容價值（D12） | 各類支數差距 ≤ 2 支 |

## 7. 剪輯規則

15–60 秒的原片原則上**不剪**。

### 7.1 共同規則（所有剪輯都適用）

1. **保留開場**，不可剪掉或重排片段的前 10 秒（開場就是操弄）
2. 只整段刪除，不在對白中間切
3. 剪輯點要在場景轉換或句子結束處
4. 不加任何新的字幕、音效、轉場；可以刪除片頭片尾字卡、「關注看下集」等平台字卡，並記錄
5. 剪輯紀錄寫進編碼表 A5（原長、剪輯後長度、起訖秒數、刪除段落）

### 7.2 從較長的單集取片段

TikTok 上的 AI 微短劇多半是 3–10 分鐘以上的單集，可以從中剪出 15–60 秒的片段。

1. **起點**：原則上從該集第 0 秒開始。若開頭是「前情提要」或片頭字卡，起點改為之後第一個場景的開始，並記錄。**不從集數中段任選起點**，否則開場是研究者挑的，scent 操弄會變成研究者製造的
2. **優先用第 1 集**：第 1 集的開頭不需要前情就看得懂；其他集要確認不看前集也能理解
3. **終點**：落在 15–60 秒之間的場景結束處。若找不到，就在句子結束處切，並在編碼表標記結尾類型：
   - `open`：開放式結尾，故事還沒走到結局就停住，接下來的發展留給觀眾
   - `closed`：封閉式結尾，場景或故事走到一個結局
4. 結尾類型是研究的分析重點（proposal v3），各組 `open` 的比例要相近（第 6 節）；原片也要編
5. 同一部劇只取 1 段進正式片庫（第 3 節排除條件 8）
6. 記錄原集網址、集數、起訖秒數，方便審查與複製研究

## 8. 轉檔與音量

全部影片統一處理，避免「高 scent 比較大聲、比較清楚」造成混淆。

| 項目 | 規格 |
|---|---|
| 編碼 | H.264（影像）＋ AAC（聲音），MP4 |
| 解析度 | 720 × 1280，30 fps |
| 響度 | 正規化到 −14 LUFS（整合響度），真峰值 ≤ −1 dBTP |
| 檔名 | `{組別}{序號}.mp4`，例如 `HS-A01.mp4`、`LS-B17.mp4` |

參考指令（ffmpeg，兩段式響度正規化的簡化版）：

```bash
ffmpeg -i input.mp4 \
  -vf "scale=720:1280:force_original_aspect_ratio=decrease,pad=720:1280:(ow-iw)/2:(oh-ih)/2,fps=30" \
  -af "loudnorm=I=-14:TP=-1:LRA=11" \
  -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k \
  HS-A01.mp4
```

### 剪片段（第 7.2 節）

```bash
# 從第 3.2 秒剪到第 48.5 秒（重新編碼，切點才準確），同時套用上面的尺寸與響度設定
ffmpeg -ss 3.2 -to 48.5 -i episode01.mp4 \
  -vf "scale=720:1280:force_original_aspect_ratio=decrease,pad=720:1280:(ow-iw)/2:(oh-ih)/2,fps=30" \
  -af "loudnorm=I=-14:TP=-1:LRA=11" \
  -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k \
  LS-A07.mp4
```

### 鏡頭切換偵測（編碼簿 D8 的初值）

```bash
# 列出前 10 秒內畫面變化超過門檻的時間點（門檻 0.3 為常用起點，pilot 時依誤判情況調整）
ffmpeg -i HS-A01.mp4 -t 10 \
  -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep -o 'pts_time:[0-9.]*'
```

輸出的每一行是一次可能的切換。程式結果只當初值，編碼者要逐一確認，例如快速晃動的手持鏡頭可能被誤判為切換。

## 9. 刺激材料前測

目的是讓操弄檢核有高齡者本身的判斷，不只是研究者編碼。這是篩選刺激材料用，不是正式量表。

- **對象**：5–8 位 60 歲以上、不參加正式實驗的高齡者
- **程序**：每支影片只播前 10 秒，播完問：「如果在手機上滑到這支，您會想繼續看嗎？」（1 = 一定滑走，5 = 一定繼續看）
- **順序**：每位前測者的播放順序隨機
- **標準**：
  - 高 scent 影片平均 ≥ 3.5，低 scent 影片平均 ≤ 2.5
  - 不符合的影片，先回頭確認編碼；仍不符合就換掉
- 前測分數記在編碼表 `pretest_mean`

## 10. 存放與倫理

- 原始檔與處理後的檔案存在有權限控管的研究雲端（僅研究團隊可存取），**不放進 GitHub**
- 施測手機只存處理後的檔案，施測期結束後刪除
- IRB 申請書說明：刺激材料為公開影片的片段，僅供研究使用，不公開散布
- 影片清單（ID、原始網址、下載日期）另存一份，供審查或複製研究使用

## 11. 流程總覽

```
蒐集候選影片（目標約 200 支）
  → 排除條件篩選
  → 兩位編碼者獨立編碼（編碼簿 A–D）
  → 信度檢核，討論不一致
  → 判定高／低 scent、mismatch，剔除「不確定」
  → 前測
  → 分組與配對檢查
  → 剪輯、轉檔、響度正規化
  → 編碼結果寫入 js/config.js
```
