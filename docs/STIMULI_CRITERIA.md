# 刺激影片選片標準

版本：v1.0（2026-10-07）｜對應 proposal v3：*No Ending in Sight*（受試者內設計，介面摩擦 2 個 5 分鐘 block）

本文件規定「哪些影片可以進入片庫、如何分組、如何處理」。每支影片的判定細節見 [`CODEBOOK.md`](CODEBOOK.md)。

> v1.0 依研究方向調整（設計紀錄 D18、D20）縮減：不再依開場 scent 分組，也不再配對 mismatch、視覺顯著性與內容價值。舊版完整保存在 [`archive/STIMULI_CRITERIA_v0.5_scent.md`](archive/STIMULI_CRITERIA_v0.5_scent.md)。

## 1. 片庫規模與分組

| 組別 | 正式施測 | pilot |
|---|---|---|
| A | 30 支 | 20 支 |
| B | 30 支 | 20 支 |
| 練習（P01、P02） | 2 支 | 2 支 |

- 每個 block 播放一組影片；A、B 兩組在一半受試者用於零摩擦、另一半用於微摩擦（序列 1–4，見 `docs/ASSIGNMENTS.md`）
- 每組 30 支足以涵蓋平均每支停留 10 秒以上的受試者；pilot 後依實際停留時間分布調整
- 同一位受試者不會重複看到同一支影片
- 候選影片清單見 [`CANDIDATES.md`](CANDIDATES.md)

## 2. 納入條件（全部符合）

1. **AI 生成的微短劇**：畫面或配音可辨識為 AI 生成（編碼簿 A8）
2. **長度 15–60 秒**：有可理解的開頭；可以是原片，也可以是從較長單集剪出的片段（第 6.2 節）
3. **劇情類型**：以家庭、婆媳、祖孫、生活喜劇等日常題材為主，兩組的類型分布相近（編碼簿 A11）
4. **直式 9:16**，原始解析度至少 720p
5. **語言**：國語為主；台語、客語或其他語言另外標記（編碼簿 A10），兩組比例一致
6. **有字幕**（高齡者常關靜音或聽力受限，字幕是主要資訊來源）
7. **公開可取得**，並記錄原始網址與下載日期

## 3. 排除條件（任一符合即排除）

1. 政治、宗教宣傳、選舉相關
2. 血腥暴力、性暗示、自傷或自殺情節
3. 醫療、投資、保健食品等可能誤導受試者的具體建議
4. 導購、業配、明顯廣告或 QR code
5. 近期爆紅、受試者可能已看過（播放數極高或曾登上新聞）
6. 真人明星或可辨識公眾人物的臉
7. 片頭或片尾有無法去除、且與其他影片不一致的品牌浮水印
8. 同一部劇在正式片庫中已有 1 段（避免受試者把同一劇的下一段當成續集繼續看）；第 2 段只能作練習或備用
9. 來源不明的轉載（標示「紅果短劇」「快手」「全集整合」等搬運帳號），除非找得到原作者並取得同意
10. 同一創作者帳號在同一組已有 3 支

## 4. 結尾類型（主要分析變項）

結尾類型不操弄，而是**每支影片都編碼**（編碼簿 B），在 feed 中自然出現。

- **open**：影片停住時，影片本身提出的最後一個問題沒有在影片內出現結果
- **closed**：影片內提出的問題在影片內出現了結果

**比例**：每組 open 與 closed 各約一半（30 支中各 12–18 支）。

**排列**：每組影片以固定順序播放，所有受試者相同；排列時同一類型不連續超過 3 支，讓每位受試者在 5 分鐘內都會遇到兩種結尾。

## 5. A、B 兩組配對

建組後用編碼資料檢查，差異過大就互換影片。

| 項目 | 配對標準 |
|---|---|
| 影片長度 | 平均差距 ≤ 5 秒 |
| 長度分布（15–29、30–44、45–60 秒三段） | 各段支數差距 ≤ 2 支 |
| 結尾類型為 `open` 的支數 | 差距 ≤ 2 支 |
| 原片與剪輯片段的比例 | 差距 ≤ 3 支 |
| 劇情類型分布（編碼簿 A11） | 各類型支數差距 ≤ 3 支 |
| 語言、AI 配音比例 | 相同或差距 ≤ 2 支 |

## 6. 剪輯規則

15–60 秒的原片原則上**不剪**。

### 6.1 共同規則（所有剪輯都適用）

1. **保留開場**，不可剪掉或重排片段的開頭
2. 只整段刪除，不在對白中間切
3. 剪輯點要在場景轉換或句子結束處
4. 不加任何新的字幕、音效、轉場；可以刪除片頭片尾字卡、「關注看下集」等平台字卡，並記錄
5. 剪輯紀錄寫進編碼表 A5、A7（原長、剪輯後長度、起訖秒數、刪除段落）

### 6.2 從較長的單集取片段

TikTok 上的 AI 微短劇多半是 3–10 分鐘以上的單集，可以從中剪出 15–60 秒的片段。

1. **起點**：原則上從該集第 0 秒開始。若開頭是「前情提要」或片頭字卡，起點改為之後第一個場景的開始，並記錄。**不從集數中段任選起點**，避免開頭由研究者挑選
2. **優先用第 1 集**：第 1 集的開頭不需要前情就看得懂；其他集要確認不看前集也能理解
3. **終點**：落在 15–60 秒之間的場景或句子結束處。**終點決定結尾類型**，所以不要為了湊比例刻意挑停在問題中間或結果之後的位置；先選最自然的場景結束處，再依剪好的版本編碼
4. 同一部劇只取 1 段進正式片庫（第 3 節排除條件 8）
5. 記錄原集網址、集數、起訖秒數，方便審查與複製研究

## 7. 轉檔與音量

全部影片統一處理，避免某些影片比較大聲、比較清楚。

| 項目 | 規格 |
|---|---|
| 編碼 | H.264（影像）＋ AAC（聲音），MP4 |
| 解析度 | 720 × 1280，30 fps |
| 響度 | 正規化到 −14 LUFS（整合響度），真峰值 ≤ −1 dBTP |
| 檔名 | `{組別}{序號}.mp4`，例如 `A01.mp4`、`B17.mp4`；練習 `P01.mp4`、`P02.mp4` |

參考指令（ffmpeg，兩段式響度正規化的簡化版）：

```bash
ffmpeg -i input.mp4 \
  -vf "scale=720:1280:force_original_aspect_ratio=decrease,pad=720:1280:(ow-iw)/2:(oh-ih)/2,fps=30" \
  -af "loudnorm=I=-14:TP=-1:LRA=11" \
  -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k \
  A01.mp4
```

### 剪片段（第 6.2 節）

```bash
# 從第 3.2 秒剪到第 48.5 秒（重新編碼，切點才準確），同時套用上面的尺寸與響度設定
ffmpeg -ss 3.2 -to 48.5 -i episode01.mp4 \
  -vf "scale=720:1280:force_original_aspect_ratio=decrease,pad=720:1280:(ow-iw)/2:(oh-ih)/2,fps=30" \
  -af "loudnorm=I=-14:TP=-1:LRA=11" \
  -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k \
  B07.mp4
```

## 8. 存放與倫理

- 原始檔與處理後的檔案存在有權限控管的研究雲端（僅研究團隊可存取），**不放進 GitHub**
- 施測手機只存處理後的檔案（由設定頁匯入，見 README），施測期結束後刪除
- IRB 申請書說明：刺激材料為公開影片的片段，僅供研究使用，不公開散布
- 影片清單（ID、原始網址、下載日期）另存一份，供審查或複製研究使用

## 9. 流程總覽

```
蒐集候選影片（CANDIDATES.md）
  → 排除條件篩選
  → 剪輯（需要時）
  → 兩位編碼者獨立編碼（編碼簿 A–D）
  → 信度檢核，討論不一致
  → 分成 A、B 兩組，檢查配對與結尾類型比例
  → 轉檔、響度正規化
  → 編碼結果寫入 js/config.js；影片匯入施測手機
```
